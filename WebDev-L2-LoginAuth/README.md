# Level 2 Task 4: Secure Login Authentication System

A secure and modern Login & Registration Web App built with HTML5, CSS3, and JavaScript (ES6) featuring LocalStorage authentication simulation, password visibility toggles, and password recovery for the Oasis Infobyte Internship (OIBSIP).

## 🚀 Key Features & Implementation

- [x] **User Registration (Sign Up):** Allows new users to register with name, email, and password stored safely in browser LocalStorage.
- [x] **Secure Login System:** Validates user credentials against stored records.
- [x] **Password Recovery (Forgot Password):** Enables users to reset their password using their registered email.
- [x] **Password Visibility Toggle:** Show/hide password functionality with interactive eye icons.
- [x] **Protected Dashboard View:** Displays a personalized greeting and session status upon successful authentication.
- [x] **Session Persistence:** Keeps the user logged in across page reloads until explicitly logged out.
- [x] **Responsive Glassmorphism UI:** Clean dark-mode layout built with CSS Flexbox and backdrop filters.

## 🛠️ Tech Stack

- **HTML5:** Semantic form markup.
- **CSS3:** Custom Variables, Glassmorphism design, Smooth transitions.
- **JavaScript (ES6):** State validation, LocalStorage management, DOM event handling.

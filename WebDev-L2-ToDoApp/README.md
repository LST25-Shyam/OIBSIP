# Level 2 Task 3: Modern To-Do Web App

A clean, feature-rich, and responsive To-Do Web App built with HTML5, CSS3, and JavaScript (ES6) for the Oasis Infobyte Internship (OIBSIP).

🌐 **Live Demo:** [https://oibsip-webdev-l2-todoapp-five.vercel.app/](https://oibsip-webdev-l2-todoapp-five.vercel.app/)

---

## 🚀 Key Features & Implementation

- [x] **Add & Edit Tasks:** Users can create tasks with titles, optional descriptions, and automatic timestamps.
- [x] **Pending vs Completed Sections:** Tasks are separated into two structured columns with live count badges.
- [x] **Status Toggle:** Instantly mark tasks as complete or revert them back to pending.
- [x] **Delete & Edit Capabilities:** Edit existing tasks or remove them individually with clean UI feedback.
- [x] **LocalStorage Persistence:** All tasks are saved in the browser's local storage so data persists across page reloads.
- [x] **Responsive Dark Theme UI:** Glassmorphism styled layout optimized for both mobile and desktop viewports.

---

## 🛠️ Tech Stack

- **HTML5:** Semantic structural markup.
- **CSS3:** Custom Variables, Modern Flexbox & Grid, Backdrop Blur, and Glassmorphism effects.
- **JavaScript (ES6):** State management, DOM manipulation, event handling, and LocalStorage synchronization.

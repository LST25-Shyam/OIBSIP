# Level 2 Task 3: Modern To-Do Web App

A clean, feature-rich, responsive To-Do Web App built with HTML5, CSS3, and JavaScript (ES6) for the Oasis Infobyte Internship (OIBSIP).

## 🚀 Key Features

- [x] **Add & Edit Tasks:** Users can create tasks with titles, descriptions, and automatic creation timestamps.
- [x] **Pending vs Completed Sections:** Tasks are separated into two structured columns with live task count badges.
- [x] **Status Toggle:** Easily mark tasks as complete or revert them back to pending.
- [x] **Delete & Edit Capabilities:** Edit existing tasks or remove them individually.
- [x] **LocalStorage Persistence:** All tasks are saved locally in the browser so data persists across refreshes.
- [x] **Responsive Layout:** Optimized dark-mode UI with flex/grid containers for mobile and desktop screens.

## 🛠️ Tech Stack

- **HTML5:** Semantic layout structure.
- **CSS3:** Custom Variables, Modern Flexbox & Grid, Backdrop Blur, Glassmorphism design.
- **JavaScript (ES6):** State management, DOM manipulation, and LocalStorage integration.

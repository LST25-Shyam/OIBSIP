# Level 2 Task 2: Tribute Page (Rabindranath Tagore)

A responsive, elegant, and modern Tribute Page dedicated to **Rabindranath Tagore** built with HTML5 and CSS3 for the Oasis Infobyte Internship (OIBSIP).

## 🚀 Feature Checklist

- [x] **Page Title & Tagline:** Name and tagline as Asia's First Nobel Laureate.
- [x] **Prominent Image:** Public domain image sourced from Wikimedia Commons.
- [x] **Biography Section:** 4 paragraphs detailing his life, Rabindra Sangeet, Nobel Prize, and legacy.
- [x] **Key Achievements Timeline:** Ordered timeline highlighting major historical milestones.
- [x] **Quote Block:** Notable quote from *Gitanjali* styled distinctly.
- [x] **Multiple Background Colors:** Smooth sectioning using dark theme palettes (`#0f172a`, `#1e293b`, `#111827`).
- [x] **Dual Font Styles:** Google Fonts — `Cinzel` (Serif) for headings & `Plus Jakarta Sans` (Sans-serif) for body text.
- [x] **Responsive Design:** Optimized across all device screens using CSS Flexbox and Media Queries.

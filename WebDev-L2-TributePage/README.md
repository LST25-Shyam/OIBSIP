# Level 2 Task 2: Tribute Page (Rabindranath Tagore)

A responsive, elegant, and modern Tribute Page dedicated to **Rabindranath Tagore** (Asia's First Nobel Laureate) built with semantic HTML5 and CSS3 for the Oasis Infobyte Internship (OIBSIP).

🌐 **Live Demo:** [https://oibsip-webdev-l2-tributepage-gamma.vercel.app/](https://oibsip-webdev-l2-tributepage-gamma.vercel.app/)

---

## 🚀 Feature Checklist Implementation

- [x] **Page Title & Tagline:** Subject's name with a styled tagline as Asia's First Nobel Laureate.
- [x] **Prominent Image:** Public domain image sourced from Unsplash / Wikimedia Commons.
- [x] **Biography Section:** 4 detailed paragraphs covering early life, Rabindra Sangeet, Nobel Prize, and legacy.
- [x] **Key Achievements Timeline:** Custom styled ordered timeline highlighting major historical milestones.
- [x] **Quote Block:** Distinctly styled inspirational quote from *Gitanjali*.
- [x] **Multiple Background Colors:** Smooth sectioning using dark theme palettes (`#0f172a`, `#1e293b`, `#111827`).
- [x] **Dual Font Styles:** Google Fonts — `Cinzel` (Serif) for headings & `Plus Jakarta Sans` (Sans-serif) for body text.
- [x] **Responsive Layout:** Optimized across all device screens using CSS Flexbox and Media Queries.

---

## 🛠️ Tech Stack

- **HTML5:** Semantic structural elements (`header`, `section`, `figure`, `blockquote`, `footer`).
- **CSS3:** Custom Variables, Flexbox, Typography hierarchy, and Responsive Media Queries.

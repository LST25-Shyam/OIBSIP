# Level 2 Task 1: Vanilla JavaScript Calculator

A responsive, interactive, and user-friendly browser-based calculator built with HTML5, CSS3, and modern Vanilla JavaScript.

🌐 **[View Live Demo](https://oibsip-webdev-l2-calculator-silk.vercel.app/)**

## 🚀 Features

- **Standard Operations:** Addition, Subtraction, Multiplication, and Division.
- **Operator Chaining:** Perform sequential mathematical operations seamlessly.
- **Error Handling:** Gracefully handles edge cases like division-by-zero (`Cannot divide by zero`) without crashing.
- **Decimal Logic:** Prevents multiple decimal points in a single operand.
- **Keyboard Navigation:** Full support for physical keyboard entries (numbers, basic operators, `Enter` for equals, `Backspace` for delete, and `Escape` for clear).
- **Responsive Layout:** Designed with CSS Grid and Flexbox for mobile and desktop screens.

## 🛠️ Tech Stack

- **HTML5:** Semantic structure and layout.
- **CSS3:** Custom styles, CSS Grid, Flexbox, and hover states.
- **JavaScript (ES6+):** Pure Vanilla JS DOM manipulation and evaluation logic.
